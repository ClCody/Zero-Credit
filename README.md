# 🎴 ZERO CREDIT (TWA)
> **Гротескная сессионная RPG в формате Telegram Mini App для студентов кафедры Информационной Безопасности (ДИБББ-11, АГТУ).**  
> *Вдохновлено механикой стакающихся реликвий Risk of Rain 2, карточным безумием Balatro, эстетикой подпольного аниме-казино (Kaiji, Kakegurui) и суровой реальностью академической балльно-рейтинговой системы.*

---

## 🎪 О Проекте

**Zero Credit** превращает учебный семестр в смертельный забег (Run) по подпольному кибер-балагану. Здесь нет закрытых баз вопросов или интеграций с неповоротливыми серверами вуза — вся игровая надстройка развернута локально для учебной группы.

Реальные академические события (посещения лекций, ответы у доски, лабораторные работы, контрольные точки и сессионные баталии) фиксируются доверенным Старостой-Арбитром и мгновенно конвертируются в игровой опыт ($XP$), звонкие Жетоны Фортуны, ключи от ящиков с реликвиями и урон по преподавателям-боссам.

---

## 🃏 Ключевые Механики

1. **Академический маппинг АГТУ**:
   * **Посещение пары** $\rightarrow$ $+XP$ (Фишки Азарта). Повышает уровень аккаунта, открывает слоты под реликвии.
   * **Ответ у доски / Сдача лабы** $\rightarrow$ $+$ Жетоны Фортуны (Chips). Валюта для покупки сундуков.
   * **Контрольная Точка (КТ)** $\rightarrow$ Прямой урон по HP-бару босса дисциплины + Шутовские Отмычки.
   * **Автоматы ($\ge 65$ / $\ge 85$)** $\rightarrow$ *Insta-Kill Execution* (Мгновенная казнь босса до экзаменационного боя с выпадением легендарного лута).

2. **Стакающийся Лут (Risk of Rain 2 Style)**:
   * Предметы делятся на Белые (обычные), Зеленые (редкие), Красные (легендарные) и Лунарные (проклятые).
   * Эффекты предметов суммируются аддитивно и мультипликативно, позволяя собирать безумные билды на разгон золота, уклонение от штрафов и криты по КТ.

3. **4 Специализированных Класса ИБ**:
   * **Шулер-Аналитик** (контроль вероятностей, Artifact of Command), **Крипто-Иллюзионист** (сохранение стриков и ZK-Proof защита), **Редтимер-Штурмовик** (взрывной урон по лабам и боссам) и **Крупье-Дипломат** (скидки в Балагане и перераспределение урона в синдикате).

4. **Синдикаты (Студенческие Бригады)**:
   * Объединения студентов в ячейки по 2–4 человека для совместной сдачи лабораторных и рейдовых ударов по общему пулу здоровья босса.

5. **Карточные Дейлики и Аномалии Балагана**:
   * Ежедневные микро-квесты (вопрос лектору, сдача без правок с 1-й попытки, спринт лабы).
   * Еженедельные модификаторы семестра («Счастливые Семёрки и Число Дьявола», «Стеклянная Неделя»).

6. **Сделка с Кардистри (Кредит Нулевого Баланса)**:
   * Механика комбэка для отстающих. Получи легендарный артефакт в долг, но закрой академические долги в срок — иначе наступит Банкротство.

7. **Публичный Аудит-Лог (ИБ-стандарт)**:
   * Абсолютная прозрачность всех действий Старосты. Каждое начисление логируется с SHA-256 хешем и видно всей группе.

## 🛠 Технологический Стек

* **Frontend**: React 19, TypeScript, Vite, Tailwind CSS.
* **UI/UX & VFX**: Framer Motion (карточные флипы, распаковка сундуков), Canvas/WebGL (эффект монохромного цифрового глитча для ультимейта).
* **Audio**: Web Audio API (генерация 8-битного процедурного звука, щелчков карт и саб-баса без тяжелых внешних MP3/WAV).
* **Telegram Integration**: `@telegram-apps/sdk` (валидация `initData`, Haptic Feedback, поддержка нативной темы Telegram).
* **Backend**: FastAPI (Python 3.11+) или Node.js (Fastify/Express).
* **База Данных**: SQLite (для быстрого старта на уровне группы) / PostgreSQL.
